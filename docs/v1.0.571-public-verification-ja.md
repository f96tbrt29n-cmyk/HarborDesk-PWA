## iPhoneの更新・実機確認

1. Safariでオンライン起動し、メニューの更新確認から「今すぐ更新」を実行します。アプリ情報がv1.0.571/build 571であることを確認します。表示が旧版なら[更新リセット](https://f96tbrt29n-cmyk.github.io/HarborDesk-PWA/refresh.html)を使います。Safariのサイトデータ削除やアプリ削除は避けてください。
2. 艦娘の個体ID・Lv、装備数・改修値、資源、保存編成の装備位置・増設、同期司令部Lv、プランナーを更新前と比較します。
3. ホーム画面PWAでもオンライン起動して更新します。Safariとは保存領域が異なる場合があるため、両方でデータを確認します。
4. PWAを終了し、機内モードで再起動して台帳・保存編成・プランナーを表示できるか確認します。オンラインへ戻し、通常の同期を実行して欠損情報の誤消去がないことを確認します。
5. [手持ち配備の実機手順](owned-loadout-verification-ja.md)に沿って探索→保存→再読込→プランナー反映、タップ操作、画面の横はみ出しを確認します。
