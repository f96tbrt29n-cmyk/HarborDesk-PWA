# PR152の継続方針

利用者が採用した[継続方針コメント（2026-10-28）](https://github.com/f96tbrt29n-cmyk/HarborDesk-PWA/pull/152#issuecomment-6463228430)を、以後の実装・検証・通常pushへ適用する。PR現状欄と[59行×4項目の進捗表](route-workflow-progress-ja.md)を共通記録とし、Workから会話・未コミットファイル・private原本が自動共有されるとは扱わない。

- 開始時にリモートHEAD、作業ツリー、進行中作業・CIと台帳を確認する。既存変更と原本を保持し、重複作業を避ける。
- 関連する経路条件・手持ち自動配備・具体的な不足/未判定案内・保存/編集/loadを一単位で確認する。具体的欠陥だけを最小修正し、既存証拠、Node境界検査、代表C/W操作を使う。期限・探索条件・アサーションを緩和せず、成功目的の反復は行わない。
- 各単位で結果・閉じた残件・未解決・236セル差分の根拠・対象SHA/CI・次の対象と選定理由を記録する。最終smokeは単位ごとに1回、自動/手動起動を重複させない。初回失敗・retry成功・最終失敗と欠測を分ける。
- 許可済み範囲では、台帳から次の対象を選んで継続する。海域ごとの定型継続許可は求めない。出典待ちは未確認として残し、独立して進められる項目へ進む。
- **新たなデータ喪失、明確な回帰、環境/権限の阻害、利用者判断が必要な仕様変更では停止する。** 対象HEAD、確認済み事実・欠測、具体的判断点をPR現状欄と台帳へ残す。根拠のない修正や回避で通さない。
- 無関係な既知CI失敗は試行別原本を保持し、今回変更との関連根拠がなければ調査を広げない。private原本・保存値・認証情報は公開記録やcommitへ含めない。
- 59行×4項目=236セルの判定基準を維持する。「一部」を任意の比率へ換算せず、コード接続や別行の成功を実操作完了へ流用しない。
