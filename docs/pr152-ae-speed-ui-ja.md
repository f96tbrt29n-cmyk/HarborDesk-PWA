## 根拠・適用範囲

[既存の分岐登録記録](verified-route-branches-ja.md)で2026-10-13に確認した [ぜかまし1-2](https://zekamashi.net/kancolle-kouryaku/1-2/) と [艦娘百科1-2](https://zh.kcwiki.cn/wiki/镇守府海域/1-2) の登録範囲を再利用。公式が保証する分岐仕様ではなく攻略資料の観測条件で、今回新しく全分岐/最新版を調査した意味ではない。

- 始点→A：4〜5隻、駆逐＋海防がちょうど4隻。
- A→E：高速統一、または軽巡1＋駆逐4。登録例の軽巡1＋駆逐4は低速可。高速化を一律に強制しない。
- 低速軽巡＋海防混在は資料間の表記不一致を引き続き未判定とする。別の高速統一条件を確認できればその根拠で判断する。
- 索敵の数値・電探/ドラム装備艦数・数値制空をこの経路へ追加しない。夜戦の戦闘推奨・勝利・任務達成とは別。

登録例の選択肢から保存編成を使い、高速統一側は既存対照と同じ自由枠の隼鷹改二＋駆逐4で確認。登録プリセットや推奨艦数を追加したのではない。低速の隼鷹改二は通常枠にタービン1＋缶1を載せると高速という既存の速力レシピを使用し、同じ艦に両部品が載ったことを独立した装備名集合と有限個数で検査する。他艦への分散で目標達成とはしない。軽巡例は夕張改二特＋駆逐4。

海域1-2→例0→合成の保存編成→手持ちで配備を探す→必須条件と艦別・部品別の案内を確認→保存または理由付き中止→同じ再読込文書のload/complete後に再表示・再評価。

|条件|実画面・操作|保存後|
|---|---|---|
|成立|隼鷹にタービンだけ配備済み、缶1＋タービン1を登録。在庫から缶を同じ隼鷹へ追加、全5艦が高速。始点の4駆逐と5隻を維持。各部品の使用は登録数以内で、主/増設の搭載可否も実マスター検査に通る|配備を保存。計算案にreadyを保存し、load後も同じ配備と経路成立|
