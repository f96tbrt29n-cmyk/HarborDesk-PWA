# 4-5中央 ADHKT／CDHKT：H・Kの優先条件

対象は `4-5/index1/default`、登録群 `ADHKT / CDHKT`。基準は `8aa17ad4e0e27b9b4475a2ea1412f06201e71878`。元の編成例「戦艦級2＋重巡2＋正規空母1＋軽空母1」と利用者指定の対地担当艦セットは保持する。今回の成立とは、選択したK経由の条件を満たすことであり、H→Tの近道でボスへ行けることや戦闘勝利とは別である。

## 出典・定義・進入経路

[登録元・ぜかまし](https://zekamashi.net/kancolle-kouryaku/4-5/)と参照先の[舰娘百科](https://zh.kcwiki.cn/wiki/西方海域/4-5)の取得済みHTMLを再利用し、H/Kの上からの優先順を照合した。ぜかましは舰娘百科を参照するため、一致を独立した出撃記録の件数に換算しない。構造図確認に必要な原寸800×480画像だけを新たに保存し、元画像は加工しない。新たな実ゲーム出撃・性能計測は行わない。

戦艦級は戦艦・高速戦艦・航空戦艦。空母系は正規空母・装甲空母・軽空母、正規空母数は正規＋装甲だけ。軽巡は軽巡洋艦だけで、雷巡・練巡を含めない。護衛数は駆逐＋海防。潜水系は潜水艦＋潜水空母で、潜水母艦は別である。4-4で扱った特殊艦種の未判定を、この海域へ根拠なく移植しない。

始点A/Cはランダム。A/Cの能動分岐でDを選び、D→Hへ進むのが今回の登録範囲である。FやEを経由したという条件を、この直接D経由へ混ぜない。

| 地点 | 上から優先する条件・結果 |
| --- | --- |
| H | 有効な高速＋以上統一、かつ戦艦級＋空母系4隻以下→T。次に軽巡1以上＋護衛3以上→T。次にF経由の場合に限り、軽巡1以上＋護衛ちょうど2→T。それ以外はK。 |
| K | 戦艦級＋正規・装甲空母4隻以上→M。次に戦艦級＋空母系5隻以上→M。その後、E経由の条件が先行する。潜水系1隻以上ではMへ逸れる可能性が索敵判定より先にある。その条件を通過した場合に数値索敵でT/Lを判定する。 |

従って、K経由を選択していても、有効な高速＋以上統一かつ戦艦級＋空母系4隻以下、または軽巡＋護衛3以上ならHからTへ短縮される。選択経路と違うため経路の見直しへ案内し、装備購入で解消する不足やボス到達不可能とはしない。直接D→Hなので、軽巡1＋護衛2だけをF経由の近道条件として適用しない。

速力未判定ではH→Kを確定しない。ただし別の有効な既知艦が高速＋未満であれば、艦隊全体の高速＋統一にはならないことを保持する。装備不可・無効な高速化セットを、確定した低速の根拠へ使わない。軽巡＋護衛3の近道、既知の潜水系、既知の重量艦上限超過などが選択経路の結果を決める場合は、別の未知入力で消さない。

潜水艦・潜水空母を含むK経由では、索敵値を満たしてもM逸れの可能性が残る。潜水母艦は同じ除外条件にしない。map全体へ潜水系不可を追加するものではない。index0の有効高速＋最短とindex2の軽巡＋護衛3最短はH→Tが先行してKに入らず、Kの潜水系条件をそのまま適用できない。

## 索敵70と既存の登録安全域71

現在の出典表はKから33式係数2で70以上→T、60以上70未満はランダム域、60未満→Lとする。舰娘百科には、司令部係数0.35の計算法なら76以上という別表記もある。製品の現行計算は係数0.4の司令部補正である。

一方、既存契約は `los(2,71)`、`map-advanced-data.js`も中央71以上と登録している。この71は既存の登録安全域として維持し、出典の厳密閾値が71と確認できたとはしない。導入履歴は `707e4a51` であり、旧担当艦記録は2026-10-26取得の出典を参照するが、今回新しい余裕量を推測していない。70と71の差や司令部Lv別の余裕は根拠の範囲を分けて残し、推測で数値を下げない。71未満の登録目標不成立を、実ゲームで不可能・購入必須の証明にしない。

数値未取得、同期不足、装備変更による未確認の艦固有索敵ボーナスは既存どおり未判定である。H/Kの既知の経路不一致がある場合は、それを数値未判定で消さない。

## 確認した接続不足と再利用する証拠

修正前の実関数対照は索敵80/係数2とゲーム反映readyだけを制御入力とし、ブラウザーや実ゲームの索敵観測とはしない。旧index1契約には重量艦上限と索敵安全域だけがあり、H→Kになる条件とKの先行する潜水系ランダムが接続されていなかった。例えば、元の編成例の全艦が有効な高速＋以上なら、実際にはH→Tへ進む。非高速＋の戦艦1＋正規空母1＋重巡2＋軽巡1＋潜水艦1ではH→Kへ進むが、Kでは索敵値より先にM逸れが残る。後者は旧編成例の基本範囲判定が未判定として止める場合もあるため、旧UI全体で成立表示を観測したとは、実際の対照なしに記載しない。
