# 4-4 AEIK：分岐の代替編成と確認範囲

対象は `4-4/index0/default`、登録経路 `AEIK`。基準は `2f2b78d4ebd63b9dd4e999635fc35cfc76985d95`。元の編成例「戦艦1＋正規空母2＋重巡1＋駆逐2」は保持し、編成例と経路の必須条件を分ける。6隻の登録範囲であり、別経路やランダムをボス到達不可能とは扱わない。

## 出典と定義

[登録元・ぜかまし](https://zekamashi.net/kancolle-kouryaku/4-4/)の詳細表と艦種定義を、参照先の[舰娘百科](https://zh.kcwiki.cn/wiki/西方海域/4-4)、[攻略Wiki](https://wikiwiki.jp/kancolle/西方海域/4-4)の表・敵編成と照合した（2026-10-28）。ぜかましは舰娘百科の詳細表（2023-12-07確認）と攻略Wikiの編成節（2021-08-07確認）を参照するため、記事間の一致を独立した出撃記録の件数に換算しない。環境停止前に保存したHTML2件・Web取得本文・原寸800×480画像を再利用し、回復後にハッシュの一致を確認した。新しい実ゲーム出撃や元出撃の復元は行っていない。

戦艦級は戦艦・高速戦艦・航空戦艦。正規空母数は正規空母＋装甲空母で、軽空母とは別。重巡級は重巡＋航巡。軽巡は軽巡洋艦だけで、雷巡・練巡は含めない。護衛数は駆逐＋海防。潜水系は潜水艦＋潜水空母で、潜水母艦・補給艦とは別である。

Eの海防条件と軽巡/重巡級条件が同時に成立する場合は、記事の多数決でI固定にしない。例えば戦艦1＋軽巡1＋海防3＋駆逐1、潜水母艦1＋重巡1＋軽巡1＋海防2＋駆逐1は、この優先順の根拠待ちを残す。海防艦を一律2隻までとする確定不一致にも変換しない。一方、戦艦級＋正規・装甲空母4隻以上、護衛不足、Iの固定条件不一致などが別に確定する場合は、その結果を未判定で消さない。

旧契約は最後のI条件を「正規・装甲空母ちょうど2隻」だけにしていた。しかし重巡級ちょうど2隻、または正規空母0＋軽巡1以上も独立した固定K条件である。例えば **戦艦1＋重巡/航巡2＋軽巡1＋駆逐2** は、始点・E・Iの条件を満たす。重巡級3隻を「ちょうど2隻」の代わりにはできないが、正規空母0＋軽巡の別条件が成立すればKになる。

潜水艦系を一律除外する条件も作らない。Eの潜水系4?～5隻という未確定な後段は護衛1隻以下の範囲であり、今回の護衛2隻以上・軽巡/重巡級の先行条件とは別である。重巡級2＋潜水艦系2＋駆逐2は、先行するEとIの条件でAEIKになる。潜水母艦は海防2隻と組み合わせた別の出典不一致を持つため、名前の部分一致で潜水系と同じ扱いにしない。

出典の一般注記には揚陸艦が空母扱いになる場合があると書かれるが、4-4の正規空母数への算入までは確定していない。Iがその数に依存する場合は未判定を残す。重巡級ちょうど2隻でI→Kが独立に確定する場合と区別する。工作艦などへ根拠のない一律未判定を広げない。

## 装備目標・案内と対象外の条件

この登録経路の速力統一・数値索敵・電探装備艦数・特定装備個数は通行必須として確認されない。Eの対潜セット、先制対潜、艦戦・各空母の攻撃機・防空・夜戦は戦闘上の目標であり、編成の経路判定とは別である。既定対潜1組は装備例で、海域に十分な人数や先制対潜成立人数の根拠ではない。利用者が選ぶ人数・制空目標、入力不足、探索打切りを確定不足や購入必須へ変換しない。

記事の画像96・制空目安80、敵制空最大例48に対する優勢72・確保144は戦闘上の例である。装備必要個数や経路必須値・勝利保証へ移植しない。Eは潜水艦のみの編成、Bは水上艦と潜水艦の混成、Hは水上戦の行止まりで一部編成に潜水艦を含む。B/Hを純粋な潜水戦マスと同一扱いにしない。

Gの資源分岐、B/Fの条件、護衛1隻以下での潜水系閾値などは資料に疑問符や表記差が残る。AEIKの独立した成立範囲へ流用しない。C/Jの資源増加装備も、この登録経路の通行必須や調達必要数にはしない。
