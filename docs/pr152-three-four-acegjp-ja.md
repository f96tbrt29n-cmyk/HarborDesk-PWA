# 3-4 ACEGJP：分岐と手持ち配備の確認範囲

対象は `3-4/index0/default`、登録経路 `ACEGJP`。基準は `e313f97fc6fe080893e5be628eac146bea894cc3`。元の編成例「戦艦級1＋正規空母2＋軽空母1＋軽巡1＋水母1」は維持し、同じ固定経路を満たす別編成と区別する。6隻の登録範囲であり、範囲外の実ゲーム編成を不可能とするものではない。

## 出典と優先順

登録元の[ぜかまし・3-4](https://zekamashi.net/kancolle-kouryaku/3-4/)の分岐表・艦種定義を、参照先の[舰娘百科・3-4](https://zh.kcwiki.cn/wiki/北方海域/3-4)と[攻略Wiki・3-4](https://wikiwiki.jp/kancolle/北方海域/3-4)で照合した。ぜかましは舰娘百科を参照しているため、記事間の一致を独立した出撃記録の件数に換算しない。[艦種表記](https://wikiwiki.jp/kancolle/ルート分岐/艦種表記まとめ)も参照した。

| 分岐 | 上から優先する条件と行き先 |
| --- | --- |
| 始点 | 軽巡＋駆逐＋海防0隻→A。次に戦艦級＋空母系3隻以上→A。続く潜水艦系入り、または同合計2隻はA/Bランダム。同合計1隻はB。0隻では駆逐3隻以上→D、残りはB/Dランダム。 |
| C | 軽巡＋駆逐＋海防0隻→B、正規・装甲空母3隻以上→B、戦艦級＋空母系5隻以上→B。同合計2隻ちょうど→F。その後、水母＋補給艦1隻以上→E。残る潜水母艦入りはE/Fランダム、それ以外はF。 |
| A/E/G/J | 登録元の海域図でA→C、E→Gは各1本の接続。攻略Wikiの表はG→JとJ→Pを固定としている。これらを別の索敵・装備数値条件へ置き換えない。 |

Cの最初の2条件は資料によって順序が逆だが、どちらも行き先はBであり、判定先の不一致にはならない。

戦艦級は戦艦・高速戦艦・航空戦艦、空母系は正規空母・装甲空母・軽空母。軽巡は軽巡洋艦で、重雷装巡洋艦・練習巡洋艦はこの軽巡数に含めない。潜水艦系は潜水艦・潜水空母で、潜水母艦とは別。補給艦は実際の艦種で数え、名前に「空母」や「潜水」が含まれることだけでは分類しない。

舰娘百科の概略文には潜水母艦を含む表現もあるが、同ページの詳細分岐表は水母・補給艦がない潜水母艦入りをE/Fランダムとしている。概略を根拠にE固定へ格上げしない。水母・補給艦を含む場合は、後段の潜水母艦条件より先にEを選ぶ。戦艦級＋空母系3隻以上も、始点の潜水艦系によるランダム条件より先に適用する。

## 確認した接続不足

旧契約は軽巡1隻以上を必須にしていた。しかし詳細分岐表の条件は軽巡・駆逐・海防の合計であり、重量艦4隻＋水母または補給艦1隻＋駆逐または海防1隻も、同じ固定経路を満たす。独立に固定した32編成の修正前対照では、この4通りだけが過剰な不足判定になった。

旧UIには編成例の範囲を別に判定する仕組みもあるため、「旧契約の不一致」と「旧UI全体の表示」を同一視しない。修正は実際の分岐条件と登録範囲を接続するもので、元の編成例や任務等で利用者が明示した条件を消すものではない。

揚陸艦などの特殊艦種について3-4固有の算入根拠が足りない範囲は未判定のままにする。既知の正規・装甲空母3隻などで不一致が確定している場合、別の未知艦によってその不一致を消さない。艦種・隻数は編成の見直しへ案内し、装備の購入数へ換算しない。

## 操作用の構造ガイドと経路説明

旧3-4構造データはボスをJとしてPを含まず、登録経路のC→E・E→G・J→Pも接続されていなかった。登録元の海域図の原寸800×480と分岐表から、独立に24本の有向接続とマス種別を固定し、3-4のデータ行だけを修正した。主表示の参照画像は変更しない。海域説明の軽巡を使う編成例は保持し、同じ経路で駆逐・海防を使える登録範囲も明記する。

Pがボス、D/Fがうずしお、E/K/Oが資源、I/J/Lが非戦闘。I/K/Oは行き止まりであり、図にないI→K・K→N等を追加しない。これは地形上の接続を示すガイドで、全接続を特定編成で選べるという意味ではない。F→Iの条件など、登録経路の外にある未確認分岐の条件式は作らない。

## 経路条件と戦闘・資源上の推奨

このACEGJPには速力統一・数値索敵・電探数・電探装備艦数の必須分岐条件を登録しない。高速＋は別のACFJPに関係する条件であり、この経路へ持ち込まない。Eのドラム缶・大発系は資源量の上積み向けで、Eへ入るための必須装備ではない。

制空・空母の攻撃機・対空・夜戦装備は戦闘上の推奨または利用者が選ぶ目標として別評価する。記事の制空目安175、敵パターンの優勢84・確保168は、経路通行のための固定装備数量や勝利保証にしない。装備枠・敵選択・損耗等の入力不足は未判定を維持する。
