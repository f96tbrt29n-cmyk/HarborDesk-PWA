# 3-3 ACGM：分岐と手持ち配備の確認範囲

対象は `3-3/index0/default`、登録経路 `ACGM`。基準は `f758ac807be6c9a0d5f6e580d0b95e7a5d9f511e`。登録例の「正規空母1＋軽空母1＋重巡2＋駆逐2」と、出典から確認できる同じ経路の別編成を区別する。任務などで利用者が指定した編成・旗艦条件は維持する。

## 出典と優先順

登録元の[ぜかまし・3-3](https://zekamashi.net/kancolle-kouryaku/3-3/)の分岐表・艦種定義を、参照先の[舰娘百科・3-3](https://zh.kcwiki.cn/wiki/北方海域/3-3)と[攻略Wiki・3-3](https://wikiwiki.jp/kancolle/北方海域/3-3)で照合した。各分岐は上から優先する。記事の概略や推奨編成だけから条件を補わない。ぜかましは舰娘百科を参照しているため、複数記事の一致を独立した出撃記録の件数とは扱わない。

| 分岐 | 優先する条件と行き先 |
| --- | --- |
| A | 正規・装甲空母1隻以上→C。次に戦艦級＋空母系4隻以上→C。次に同1隻ちょうど＋軽巡1隻ちょうど＋駆逐4隻ちょうど→C。それ以外→B。最初の条件に当たらない場合、正規・装甲空母は0隻なので、後続の合計は戦艦級＋軽空母と同じ。 |
| C | 駆逐＋海防1隻以下→E。次に正規・装甲空母2隻以上→E。次に戦艦級＋空母系3隻以上→E。残る同2隻ちょうど→G。次に同1隻ちょうど＋軽巡1隻ちょうど＋駆逐4隻ちょうど→G。それ以外→E。 |
| G | 潜水艦・潜水空母が1隻以上ならI/Mランダム。その後に戦艦級＋空母系3隻以下→M。4隻以上はI/Mランダム。ACGMではCの条件から合計2隻以下になるため、潜水艦系の先行条件を別に確認する。 |

戦艦級は戦艦・高速戦艦・航空戦艦。空母系は正規空母・装甲空母・軽空母。「軽巡1」は軽巡洋艦で、重雷装巡洋艦・練習巡洋艦を代わりに数えない。「駆逐4」に海防艦は含めない。Cの先行条件だけは駆逐＋海防の合計を使う。潜水母艦は潜水艦・潜水空母とは別艦種。

正規・装甲空母1＋別の戦艦級または軽空母1という編成に加え、戦艦級または軽空母1＋軽巡1＋駆逐4、正規・装甲空母1＋軽巡1＋駆逐4も、表の各条件を満たす場合の別編成として扱う。自由枠の特殊艦種については3-3固有の算入範囲を確認できていない。揚陸艦・潜水母艦・水母・補給艦・練習巡洋艦・工作艦などを含む案は未判定に残す。別の既知艦で確定した不一致があれば、その不一致は消さない。

## 修正前と修正後

修正前の経路契約は「6隻、正規・装甲空母1隻以下、戦艦級＋軽空母1隻以下、駆逐2隻以上」だけだった。このため、AでBへ進む編成、CでEへ進む編成、Gで潜水艦系のランダム分岐に入る編成を契約上は充足としていた。一方、Cが数える海防艦を駆逐の代わりに採用した編成は不足としていた。

これは経路契約の不備であり、修正前の画面全体が常に「成立」と表示したという意味ではない。別にある登録編成例との照合によって、画面全体が未判定となる場合もあった。

修正後はA/C/Gを出典の優先順に接続する。艦種・隻数の不一致は編成見直しへ案内し、装備の調達数量には換算しない。Gの固定条件から外れることをボス到達不可能とは扱わない。確認できる別編成は、元の編成例との違いだけを理由に未判定へ戻さない。艦種不明と特殊艦種の未確認範囲は未判定のまま残す。

速力統一、数値索敵、電探の個数・装備艦数は、この経路の必須分岐条件ではない。電探はCのうずしお軽減、制空・空母の攻撃機・防空・夜戦装備は戦闘上の推奨または利用者が別に選ぶ目標。推奨装備がないことを経路不成立や購入必須へ置き換えない。条件成立は戦闘勝利の保証でもない。

## 軽い境界確認

`tests/three-three-acgm.test.cjs` の期待値は、製品データを使って生成せず、上記の優先表から独立して固定した。通常艦種の24編成を直接比較した基準版では9件に差があった（海防を含む2件の過剰な不足判定、A/C条件が足りない7件の過剰な契約充足判定）。

5つの検査群は、両方のA入口、Cの隻数境界、重雷装巡洋艦・練習巡洋艦と軽巡の違い、駆逐と海防の違い、潜水艦・潜水空母と潜水母艦の違い、特殊艦種・艦種不明、既知不一致の保持、速力・装備条件の非必須、入力を変更しないことを確認する。基準版では5群とも失敗。最初の群の最初の失敗は駆逐＋海防の扱いであり、後続の異常編成までその群を実行できたとは記載しない。24編成すべての修正前の値は別の直接比較記録に保持した。

## CI確定とload後停止の追補
