# v1.0.573 開発：1-3の登録経路

公開版はv1.0.572です。この追加は別の開発ブランチで、公開前です。

2026-10-13に[ぜかましの1-3](https://zekamashi.net/kancolle-kouryaku/1-3/)と[艦これ攻略Wikiの1-3分岐](https://wikiwiki.jp/kancolle/鎮守府海域/1-3)を照合しました。攻略資料の観測条件で、公式仕様の保証ではありません。

最初の対象を「6隻・軽空母/軽巡/駆逐のみ・駆逐4隻以上」に限定しています。この範囲は正規/装甲空母、戦艦、水母、補給艦を含まないため、その優先分岐には該当しません。

| 箇所 | 登録範囲の条件と行き先 |
| --- | --- |
| 始点 | 軽空母あり→C。空母なし→A/Cランダム |
| A | 駆逐4以上→D/Eランダム。経由の確率を到達保証へ置き換えない |
| C / D / B / E | C→F、D→B→E→F。資料のCFJ/A(DB)EFJと照合 |
| F | 駆逐4以上、正規空母・低速戦艦なし→J |

通常目標はCFJまたはA(DB)EFJを許容し、全登録候補がJへ向かうか確認します。空母なしの案は固定経路と表示しません。CFJ目標では軽空母を1隻以上必要とし、低速軽空母や低速軽巡も除外しません。数値索敵や高速化装備の条件は根拠なく追加しません。戦闘勝利と航空戦力の充足は別の評価です。

37海域・53編成例は維持し、schemaVersion 2の共通グラフへデータを追加します。手持ち代替探索もCFJを再評価し、最後の軽空母を軽巡に替える案をCFJ成立と表示しません。保存/再読込/プランナーへ個体ID・装備・目標・出典付き理由を保持します。

未登録の目標がJavaScriptの予約プロパティ名と一致しても、登録済みの目標と誤認しないようにしました。未知の保存目標は選択欄にも「未登録」と表示し、明示的に選び直すまで未判定です。

少数編成、正規空母/戦艦/水母/補給/航巡/練巡/海防を含む経路、H経由、任務固有条件、ランダム分岐の確率は未登録です。この範囲外が攻略不能という意味ではなく、登録経路の到達保証を出しません。新しい性能・特殊ボーナス・HP同期処理は追加していません。

`tests/route-1-3.spec.js` は低速艦のCFJ、空母なしのランダム、範囲外、不明艦、未登録/予約名目標、所持代替の再評価、6保存系統の保持とプランナー反映を検証します。
