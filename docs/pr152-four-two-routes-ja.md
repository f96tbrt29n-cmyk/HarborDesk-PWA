# 4-2 ACL／BDCL：共通条件と経路差分

対象は `4-2/index0/default` と `4-2/index1/default`、登録群 `ACL / BDCL`。基準は `dc174887264bbc4e04a1099aeb27e7e4653be238`。元の編成例「正規空母2＋軽巡1＋駆逐3」「空母系2＋駆逐4」は保持し、編成例の空母2隻と経路の必須艦種・隻数を分ける。6隻の登録範囲であり、別の経路やランダムをボス到達不可能とは扱わない。

## 出典と判定範囲

[登録元・ぜかまし](https://zekamashi.net/kancolle-kouryaku/4-2/)の詳細表・編成節を、参照先の[舰娘百科](https://zh.kcwiki.cn/wiki/西方海域/4-2)と[攻略Wiki](https://wikiwiki.jp/kancolle/西方海域/4-2)で照合した。確認日は2026-10-28。ぜかましの詳細表は舰娘百科を参照し、固定編成節は攻略Wikiを参照する。記事の一致を独立した出撃観測の件数に換算しない。HTML・Web取得本文・原寸画像とハッシュをprivateに保持し、新規の実ゲーム出撃やNGA元出撃の復元は行っていない。

「護衛」は駆逐艦＋海防艦、「軽巡」は軽巡洋艦のみで雷巡・練巡を含めない。「重量艦」は戦艦・高速戦艦・航空戦艦・正規空母・装甲空母・軽空母。潜水系は潜水艦＋潜水空母で、潜水母艦とは別。装備や艦名の部分一致で艦種を置換しない。

両始点の全ての分岐を同じ登録群へ収めるには、潜水系なしに加え、index0は「軽巡1以上＋護衛3以上」または「護衛4以上」、index1は「護衛4以上」とする。軽巡・護衛が4隻以上を占める6隻編成なので、残りを全て重量艦としても2隻以下であり、CとDの先行する重量艦条件に触れない。空母2隻は必須ではない。残る既知非潜水艦の枠が重巡・潜水母艦・揚陸艦・工作艦等でも、この上限の推論は変わらない。一方、未知艦は潜水系を隠し得るため未判定を残す。

`ACL` は水上戦AからC、`BDCL` は潜水戦B・水上戦DからCへ進み、C→Lが共通する。2軽巡＋2護衛＋2空母は、既にCならL固定だが、AではC/Eランダムなので登録群全体の固定条件と混同しない。軽巡なし護衛3のA偏りなどは出典間で異なるが、固定でない点は一致する。今回はG/H経由や任務別の全条件まで広げない。

## 確認した未接続と案内

旧契約は軽巡・護衛条件だけで、Aに先行する潜水系のランダムを接続していなかった。例えば軽巡1＋駆逐3＋空母1＋潜水艦1、駆逐4＋空母1＋潜水空母1は、旧の隻数条件を満たしてもA→Cを固定できない。潜水母艦を同じ理由で除外しない。既知潜水系や既知の護衛不足がある場合は、別の未知艦でその不一致を消さない。

艦種・隻数による経路群の不一致は編成見直しへ案内する。潜水系入りで実ゲームのACL/BDCL通過が絶対不可能になったという意味でも、装備購入で解消する不足でもない。経路条件を満たす案でも、戦闘勝利・安全進撃・一般探索の網羅は保証しない。

この登録群に、速力統一・数値索敵・電探数・特定装備数の通行必須条件は確認されない。B対策の対潜、艦戦・各空母の攻撃機・防空・夜戦は戦闘目標で、利用者が選択する制空・先制対潜人数と分ける。既定の対潜1組は装備例であり、海域に十分な人数・先制対潜の成立人数の根拠ではない。

記事の制空画像96・目安90や、各敵例の84/85などは戦闘上の例で、装備必要個数ではない。ぜかましの表には潜水戦Bの見出しで制空値が記載される一方、他資料はDの例として記載している。見出しや目安の差を新しい経路必須値へ移植せず、既存の敵パターン・戦闘方針の利用者選択と未選択の未判定を保持する。

対潜の複数の艦名は、同じ1組を配備できる代替候補であり、全候補艦への配備数ではない。目標欄の組数、在庫0での部品不足、同じ艦の別合法通常枠、他目標との枠共用を分ける。

現行の地図装備目標生成では、Hの「制空不要」を含むマップ全体の文字列判定により、4-2の任意対空CIセット目標は生成されない。制空の選択目標や、B/Hの既存対潜セット目標とは別の接続残件として記録し、今回目標を追加したとはしない。map-node-dataの既存対潜説明を読み込む前の不完全な静的検査を、旧製品に対潜目標がなかった根拠へ使わない。

## 構造ガイドと検証

旧ガイドはA→D、D→E/Fなど登録経路にない接続を含み、C→L、D→C、F→Jなどが欠けていた。登録元の原寸800×480と詳細分岐表を独立に照合し、16有向接続を確認した。S→A/B、A→C/E、B→D、C→G/L、D→C/H、E→G、F→J、G→F/I/L、H→G/K。Lボス、B/H潜水戦、J/K資源、F/I非戦闘、I/J/K/Lは出口なし。これは構造図であり、任意の編成が全ての矢印を選べるという意味ではない。主参照画像や他海域は変更対象外。

独立期待値は出典の優先表から固定し、実装の条件式から生成しない。軽巡/雷巡/練巡、駆逐/海防、護衛2/3/4、潜水艦/潜水空母/潜水母艦、空母なしの代替、未知艦と既知不一致、速力・装備非必須、2登録例と両始点の共通部分を軽い境界検査で確認する。操作・保存は必要な代表ケースで確認し、変更のない成功証拠を再利用する。
