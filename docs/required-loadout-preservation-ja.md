# 自動配備で充足した装備条件を維持する

## 再現した問題

時雨改二の3枠に特殊高角砲・対空電探・ソナーを載せ、対空カットイン1組、対潜装備2枠、ソナー＋爆雷投射機1組を目標とした。所持装備はそれぞれ1個。

変更前は、対潜装備数と対潜シナジーの合計評価を高めるために高角砲を爆雷投射機へ交換し、充足済みの対空カットインを外していた。修正前の回帰テストで「対空CI充足→不足」を確認した。これは登録済みの推奨セットの判定であり、対空CIの実際の発動や海域の通行条件を意味しない。

## 修正

- 手持ち配備探索は、現在の最良案で確認済み・充足済みの目標を崩す候補を最終案として採用しない。目標を艦別・表示名別に識別し、速力などの個別条件も混同しない。
- 複数枠の交換でセットを移す途中の状態は探索可能にする。候補の絞り込みでは最初に充足していた条件を保つ案を優先する。
- 5種類の最適化モードでも、交換前に充足した登録目標が交換後に崩れる候補を除外する。変更前の安定重視モードでも高角砲が外れることを回帰テストで再現した。
- 空き枠の基本装備補充も、その時点で充足した目標を維持するか毎回再評価する。
- 自動編成への反映前にも、その自動編成の目標で再評価し、充足した条件を崩す結果を採用しない。
- 対潜セットと対空CIを1隻の3枠で両立できない例では対空CIを維持し、対潜不足を表示する。2隻ある例では別艦へ対潜セットを配備できることを確認する。
- 通常枠が埋まっていても対策目標が不足・未判定なら、配備結果の先頭へ項目数を表示する。
- 保存編成、再読み込み、制空・索敵プランナーへ保持した装備が反映されることを検証する。

## 範囲と限界

登録済みの装備目標、装備可否、所持数、改修値の判定を再利用する。装備を永久固定する機能ではなく、条件を満たす同等の装備交換は可能。対象の編成・台帳を変更した場合は新しい条件で再評価する。

目標間の両立が探索で見つからない場合は不足を残す。未登録装備・未確認対潜値・敵防空情報などを成立扱いにしない。全組み合わせの網羅や戦闘勝利は保証しない。保存形式や同期処理の変更は行わない。
